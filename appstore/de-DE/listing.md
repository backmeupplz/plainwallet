## Description (max 4000)
Plain Wallet ist eine sehr minimalistische Open-Source-Wallet für Ethereum und andere EVM-Netzwerke. Auf dem iPhone ist sie ein Browser mit eingebauter Wallet: Geben Sie die Adresse einer Website ein, und die Website erhält Plain Wallet als Wallet. Auf dem Mac ist sie eine Safari-Erweiterung und dieselbe Wallet in einem eigenen Fenster.

Ethereum, Base, Arbitrum, Optimism, Polygon, BNB Chain, Avalanche und Gnosis sind eingebaut, und Sie können jedes andere EVM-Netzwerk hinzufügen. Sie können den Gas-Token oder jeden ERC-20-Token senden, Ihre Guthaben und verbundenen Websites sehen und auf dem iPhone die Websites, die Sie nutzen, mit einem Stern markieren, damit sie oben auf dem Startbildschirm der Wallet bleiben.

Jede Verbindung, Signatur, Transaktion und jeder Netzwerkwechsel wartet auf Ihre Genehmigung. Diese zeigt die Website, das Netzwerk und das Konto, bei einer Transaktion außerdem Empfänger, Betrag und maximale Gebühr. Token-Freigaben und -Transfers werden in einem ganzen Satz beschrieben, und unbegrenzte Beträge werden markiert, ebenso wie Signaturen, mit denen Sie Ihre Assets aus der Hand geben könnten. Jede Transaktion wird vorher simuliert, sodass Sie Ihre Guthabenänderungen oder den Grund für ein Scheitern sehen, bevor Sie signieren.

Führen Sie eine Cold Wallet als beobachtetes Konto: Sie nutzen es wie gewohnt für Guthaben, Senden und Websites und signieren jede Anfrage in Plain Wallet auf einem anderen Gerät, das den Schlüssel hat, auch auf einem, das immer offline bleibt. Sie können eine neue Seed-Phrase erzeugen, eine Seed-Phrase oder einen privaten Schlüssel importieren und Ihren Konten Namen geben.

Ihre Seed-Phrasen und Schlüssel werden mit Ihrem Passwort verschlüsselt und bleiben auf Ihrem Gerät, und Plain Wallet sendet sie nie an einen Server. Die Wallet sperrt sich nach 15 Minuten Inaktivität. Auf dem iPhone sperrt sie sich außerdem, wenn Sie die App eine Minute lang verlassen, und auf Wunsch entsperren Sie sie mit Face ID oder Touch ID.

Plain Wallet hat keine Server, keine Benutzerkonten, keine Werbung, keine Analysen und kein Tracking, und der Entwickler erhält keinerlei Daten daraus. Sie besteht aus rund 2.850 Zeilen TypeScript mit drei Laufzeitabhängigkeiten und ist Open Source unter der MIT-Lizenz: https://git.borodutch.com/backmeupplz/plainwallet. Sie wurde nicht auditiert, bewahren Sie darin also bitte kein Geld auf, dessen Verlust Sie sich nicht leisten können.
