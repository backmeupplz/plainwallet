## Description (max 4000)
Plain Wallet 是一款极简、开源的钱包，支持以太坊和其他 EVM 网络。在 iPhone 上，它是一个内置钱包的浏览器：输入网站地址，该网站就会使用 Plain Wallet 作为它的钱包。在 Mac 上，它是一个 Safari 扩展，同一个钱包也可以在单独的窗口中打开。

内置以太坊、Base、Arbitrum、Optimism、Polygon、BNB Chain、Avalanche 和 Gnosis，您也可以添加任何其他 EVM 网络。您可以发送 Gas 代币或任何 ERC-20 代币，查看余额和已连接的网站；在 iPhone 上还可以收藏常用的网站，让它们固定显示在钱包首页的最上方。

每一次连接、签名、交易和网络切换都需要您批准。批准页面会显示网站、网络和账户；如果是交易，还会显示收款地址、金额和最高费用。代币授权和转账会用一句话说清楚，无限额的金额会被特别标出；可能让别人转走您资产的签名也会被标出。每笔交易都会先进行模拟，让您在签名之前就能看到余额将如何变化，或者交易会失败的原因。

您可以把冷钱包添加为仅观察账户：像平常一样查看余额、发送代币和使用网站，再在持有密钥的另一台设备上用 Plain Wallet 为每个请求签名，即使那台设备始终离线也没问题。您可以生成新的助记词，导入助记词或私钥，并为账户设置昵称。

您的助记词和密钥会用您的密码加密，保存在您的设备上，Plain Wallet 绝不会将它们发送到任何服务器。钱包闲置 15 分钟后会自动锁定。在 iPhone 上，离开 App 一分钟后也会锁定，您还可以选择用面容 ID 或触控 ID 解锁。

Plain Wallet 没有服务器、注册账号、广告、数据分析或跟踪，开发者不会从中收到任何数据。它约有 2,850 行 TypeScript 代码，只有三个运行时依赖，基于 MIT 许可证开源：https://git.borodutch.com/backmeupplz/plainwallet 。它尚未经过安全审计，所以请不要在其中存放您无法承受损失的资金。
