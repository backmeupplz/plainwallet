## Description (max 4000)
Plain Wallet คือกระเป๋าเงินโอเพนซอร์สที่เรียบง่ายมากสำหรับ Ethereum และเครือข่าย EVM อื่นๆ บน iPhone แอปนี้คือเบราว์เซอร์ที่มีกระเป๋าเงินในตัว เพียงพิมพ์ที่อยู่ของเว็บไซต์ เว็บไซต์นั้นก็จะใช้ Plain Wallet เป็นกระเป๋าเงิน ส่วนบน Mac แอปนี้คือส่วนขยาย Safari พร้อมกระเป๋าเงินเดียวกันในหน้าต่างของตัวเอง

Ethereum, Base, Arbitrum, Optimism, Polygon, BNB Chain, Avalanche และ Gnosis มีให้ในตัว และคุณเพิ่มเครือข่าย EVM อื่นใดก็ได้ คุณส่งโทเค็นแก๊สหรือโทเค็น ERC-20 ใดก็ได้ ดูยอดคงเหลือและเว็บไซต์ที่เชื่อมต่อไว้ และบน iPhone ยังติดดาวเว็บไซต์ที่ใช้บ่อยเพื่อให้อยู่ด้านบนสุดของหน้าจอหลักของกระเป๋าเงินได้

ทุกการเชื่อมต่อ ลายเซ็น ธุรกรรม และการสลับเครือข่ายจะรอการอนุมัติจากคุณ หน้าการอนุมัติแสดงเว็บไซต์ เครือข่าย และบัญชี และสำหรับธุรกรรมยังแสดงผู้รับ จำนวน และค่าธรรมเนียมสูงสุดด้วย การอนุมัติและการโอนโทเค็นจะอธิบายเป็นประโยคเดียว โดยทำเครื่องหมายจำนวนแบบไม่จำกัดไว้ ลายเซ็นที่อาจส่งมอบสินทรัพย์ของคุณให้ผู้อื่นก็ถูกทำเครื่องหมายเช่นกัน และทุกธุรกรรมจะถูกจำลองก่อน คุณจึงเห็นว่ายอดคงเหลือจะเปลี่ยนไปอย่างไร หรือเห็นเหตุผลที่ธุรกรรมจะล้มเหลว ก่อนที่คุณจะลงนาม

เก็บกระเป๋าเงินเย็น (cold wallet) ไว้เป็นบัญชีแบบดูอย่างเดียว ใช้ดูยอดคงเหลือ ส่ง และใช้งานเว็บไซต์ได้ตามปกติ แล้วลงนามแต่ละคำขอใน Plain Wallet บนอุปกรณ์อีกเครื่องที่เก็บคีย์ไว้ แม้จะเป็นเครื่องที่ออฟไลน์ตลอดก็ตาม คุณสร้างวลีกู้คืนใหม่ นำเข้าวลีกู้คืนหรือคีย์ส่วนตัว และตั้งชื่อเล่นให้บัญชีได้

วลีกู้คืนและคีย์ของคุณถูกเข้ารหัสด้วยรหัสผ่านของคุณและอยู่บนอุปกรณ์ของคุณ โดย Plain Wallet ไม่เคยส่งข้อมูลเหล่านี้ไปยังเซิร์ฟเวอร์ใดๆ กระเป๋าเงินจะล็อกเมื่อไม่ได้ใช้งาน 15 นาที บน iPhone กระเป๋าเงินจะล็อกเมื่อคุณออกจากแอปไปหนึ่งนาทีด้วย และคุณปลดล็อกด้วย Face ID หรือ Touch ID ได้หากต้องการ

Plain Wallet ไม่มีเซิร์ฟเวอร์ บัญชีผู้ใช้ โฆษณา การวิเคราะห์ หรือการติดตาม และผู้พัฒนาไม่ได้รับข้อมูลใดๆ จากแอป แอปนี้เป็นโค้ด TypeScript ประมาณ 2,850 บรรทัดที่มีไลบรารีที่ต้องใช้ขณะรันเพียงสามตัว เป็นโอเพนซอร์สภายใต้สัญญาอนุญาต MIT ที่ https://git.borodutch.com/backmeupplz/plainwallet แอปนี้ยังไม่ผ่านการตรวจสอบความปลอดภัย (audit) จึงไม่ควรเก็บเงินที่คุณไม่พร้อมจะเสียไว้ในแอป
