## Description (max 4000)
Plain Wallet 是一款極簡、開源的錢包，支援以太坊和其他 EVM 網路。在 iPhone 上，它是一個內建錢包的瀏覽器：輸入網站的網址，該網站就會把 Plain Wallet 當作它的錢包。在 Mac 上，它是一個 Safari 延伸功能，另外還有在獨立視窗中開啟的同一個錢包。

內建以太坊、Base、Arbitrum、Optimism、Polygon、BNB Chain、Avalanche 和 Gnosis，您也可以新增任何其他 EVM 網路。您可以傳送 Gas 代幣或任何 ERC-20 代幣，查看餘額和已連結的網站；在 iPhone 上還可以把常用的網站加入我的最愛，讓它們固定顯示在錢包主畫面的最上方。

每一次連結、簽名、交易和網路切換都要經過您核准。核准畫面會顯示網站、網路和帳戶；如果是交易，還會顯示收款地址、金額和最高費用。代幣授權和轉帳會用一句話清楚說明，無上限的金額會特別標示；可能讓別人取走您資產的簽名也會被標示出來。每筆交易都會先經過模擬，讓您在簽署前就看到餘額會如何變動，或交易會失敗的原因。

您可以把冷錢包當作僅觀察帳戶使用：照常查看餘額、傳送和使用網站，再到持有金鑰的另一部裝置上用 Plain Wallet 簽署每個請求，即使那部裝置始終保持離線也沒問題。您可以產生新的助記詞，匯入助記詞或私鑰，並為帳戶設定暱稱。

您的助記詞和金鑰會以您的密碼加密，保存在您的裝置上，Plain Wallet 絕不會將它們傳送到任何伺服器。錢包閒置 15 分鐘後會自動鎖定。在 iPhone 上，離開 App 一分鐘後也會鎖定，您也可以選擇用 Face ID 或 Touch ID 解鎖。

Plain Wallet 沒有伺服器、帳號、廣告、分析或追蹤，開發者不會從中收到任何資料。它約有 2,850 行 TypeScript 程式碼，只有三個執行階段相依套件，以 MIT 授權開放原始碼：https://git.borodutch.com/backmeupplz/plainwallet 。它尚未經過安全稽核，所以請不要在裡面存放您無法承受損失的資金。
