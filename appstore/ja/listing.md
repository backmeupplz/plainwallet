## Description (max 4000)
Plain Wallet は、イーサリアムとその他のEVMネットワークに対応した、とてもミニマルでオープンソースのウォレットです。iPhone ではウォレットを内蔵したブラウザとして動作します。サイトのアドレスを入力すると、そのサイトは Plain Wallet をウォレットとして使えます。Mac では Safari 機能拡張として動作し、同じウォレットを専用のウインドウでも使えます。

イーサリアム、Base、Arbitrum、Optimism、Polygon、BNB Chain、Avalanche、Gnosis があらかじめ組み込まれており、その他のEVMネットワークも自由に追加できます。ガス代に使うネイティブトークンや任意の ERC-20 トークンを送金でき、残高と接続済みサイトを確認できます。iPhone では、よく使うサイトにスターを付ければ、ウォレットのホーム画面の一番上に表示されます。

接続、署名、トランザクション、ネットワークの切り替えは、すべてあなたの承認を待ちます。承認画面にはサイト、ネットワーク、アカウントが表示され、トランザクションの場合は受取人、金額、最大手数料も表示されます。トークンの承認や送金は一文で説明され、無制限の金額には警告が付きます。資産を引き渡してしまう可能性のある署名にも警告が付きます。さらに、すべてのトランザクションは事前にシミュレーションされるので、署名する前に残高がどう変わるのか、あるいは失敗する理由を確認できます。

コールドウォレットは監視専用アカウントとして使えます。残高の確認、送金、サイトの利用はいつもどおりに行い、各リクエストへの署名は鍵を持つ別のデバイスの Plain Wallet で行います。そのデバイスはずっとオフラインのままでも構いません。新しいシードフレーズの作成、シードフレーズや秘密鍵のインポート、アカウントへのニックネーム付けもできます。

シードフレーズと鍵はパスワードで暗号化されてお使いのデバイスに保存され、Plain Wallet がそれらをサーバーに送信することはありません。ウォレットは15分間操作がないとロックされます。iPhone ではアプリを離れてから1分でもロックされ、必要に応じて Face ID または Touch ID でロックを解除できます。

Plain Wallet にはサーバー、アカウント登録、広告、分析、トラッキングが一切なく、開発者がこのアプリからデータを受け取ることもありません。約2,850行の TypeScript と3つのランタイム依存関係だけで作られており、MIT ライセンスのオープンソースとして https://git.borodutch.com/backmeupplz/plainwallet で公開されています。セキュリティ監査はまだ受けていないため、失っても困らない額を超える資金は入れないでください。
