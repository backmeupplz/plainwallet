Plain Wallet GitHub ↗

Eine Wallet, die Sie lesen können.

Eine sehr minimalistische EVM-Wallet für Chrome, Firefox, Safari, Android, iPhone und Mac. Rund 2.850 Zeilen TypeScript – klein genug, um sie an einem Abend zu lesen oder von Ihrem Agenten in einer Minute lesen zu lassen.

  • 3 Laufzeit-Abhängigkeiten
  • keine Server
  • keine Analyse-Tools
  • MIT

Sie sehen, was Sie signieren.

Jede Signatur erfordert einen Klick im eigenen Fenster der Wallet. Die Transaktion wird zuerst vollständig vorbereitet, und genau sie wird signiert.

  • Wissen, was Sie senden

    Empfänger, Betrag und die maximal möglichen Gebühren, bevor Sie signieren.

  • Genehmigungen im Klartext

    Token-Genehmigungen und Überweisungen werden zu einem einfachen Satz. Unbegrenzte sind rot markiert.

  • Riskante Signaturen fallen auf

    Permits und Orders, die Ihr Vermögen bewegen können, tragen eine Warnung und zeigen nur die Felder, die tatsächlich gehasht werden.

Für Mac und Safari macOS 14+ · in Prüfung im App Store

Eine App, zwei Arten der Nutzung: die Wallet in einem eigenen Fenster und die Plain-Wallet-Erweiterung für Safari, die dieselbe Wallet verwendet. Öffnen Sie nach der Installation Safari → Einstellungen → Erweiterungen, aktivieren Sie Plain Wallet und erlauben Sie es auf Websites; Websites erhalten es dann als ihre Wallet, mit denselben Genehmigungen wie in der Chrome-Erweiterung. Für Firefox auch LibreWolf · Add-on in Prüfung

Plain Wallet wartet bei den Firefox-Add-ons auf die Prüfung. Bis es dort gelistet ist, erstellen Sie es selbst und laden es vorübergehend über about:debugging, oder Sie deaktivieren in LibreWolf oder Firefox Developer Edition/Nightly xpinstall.signatures.required und öffnen die in .xpi umbenannte ZIP-Datei.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Für KI-Agenten erst den Code prüfen

Fügen Sie dies in Claude Code, Codex, Cursor oder einen anderen Agenten ein, der eine Shell ausführen kann.

Installiere mir die Browser-Erweiterung Plain Wallet von https://github.com/backmeupplz/plainwallet – aber prüfe den Code, bevor du irgendetwas installierst oder baust.

1. Klone das Repository. Führe noch nicht npm install aus: Die Abhängigkeiten haben Installationsskripte.
2. Lies den gesamten Quellcode: entrypoints/, lib/, wxt.config.ts, package.json und package-lock.json. Es sind rund 2.850 Zeilen TypeScript.
3. Suche nach allem, was Seed-Phrasen oder private Schlüssel preisgeben, Daten an etwas anderes als den vom Nutzer gewählten RPC senden, die Verschlüsselung des Tresors schwächen oder ohne ausdrückliche Genehmigung signieren könnte. Prüfe die Abhängigkeiten auf Unerwartetes.
4. Berichte, was du gefunden hast, mit Datei- und Zeilenangaben. Wenn etwas verdächtig ist, höre auf und frage mich.
5. Wenn alles sauber ist: npm ci && npm test && npm run build
6. Sag mir, wie ich sie lade: in Chrome chrome://extensions → Entwicklermodus → Entpackte Erweiterung laden → .output/chrome-mv3. Für Firefox baue mit npx wxt zip -b firefox --mv3 und folge der README.

Für Menschen

Oder erstellen Sie die Erweiterung aus dem Quellcode für Chrome, Brave, Edge und andere Chromium-Browser oder für Firefox.

  1. Klonen und bauen:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Öffnen Sie chrome://extensions, aktivieren Sie den Entwicklermodus, klicken Sie auf Entpackte Erweiterung laden und wählen Sie .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, dann laden wie oben beschrieben.

Nicht geprüft. Bewahren Sie darin kein Geld auf, dessen Verlust Sie sich nicht leisten können.

Passwort vergessen?

Es lässt sich nicht wiederherstellen: Die Wallet ist auf Ihrem Gerät damit verschlüsselt, und niemand sonst hat eine Kopie. Setzen Sie die Wallet auf dem Entsperrbildschirm zurück, importieren Sie dann Ihre Seed-Phrase oder Ihren privaten Schlüssel erneut und wählen Sie ein neues Passwort.

Seed-Phrase verloren?

Solange sich die Wallet noch entsperren lässt, exportieren Sie die Seed-Phrase in den Einstellungen mit Ihrem Passwort und schreiben Sie sie auf. Ohne sie und das Passwort kann niemand die Wallet wiederherstellen, auch wir nicht.
