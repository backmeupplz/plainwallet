Plain Wallet GitHub ↗

Een wallet die je kunt lezen.

Een uiterst minimalistische EVM-wallet voor Chrome, Firefox, Safari, Android, iPhone en Mac. Zo'n 2.850 regels TypeScript, klein genoeg om in één avond door te lezen, of door je agent in één minuut te laten lezen.

  • 3 runtime-afhankelijkheden
  • geen servers
  • geen analytics
  • MIT

Je ziet wat je ondertekent.

Elke handtekening vraagt een klik in het eigen venster van de wallet. De transactie wordt eerst volledig klaargezet en precies die wordt ondertekend.

  • Weet wat je verstuurt

    Ontvanger, bedrag en de maximale kosten aan fees, voordat je ondertekent.

  • Goedkeuringen in gewone taal

    Tokengoedkeuringen en overboekingen worden één duidelijke zin. Onbeperkte goedkeuringen krijgen een rode markering.

  • Riskante handtekeningen vallen op

    Permits en orders die je bezittingen kunnen verplaatsen krijgen een waarschuwing, waarbij alleen de velden worden getoond die worden gehasht.

Installeren

Vertrouw er niet blind op, controleer het. Daarom houden we het klein.

Voor Chrome ook Brave en Edge

Installeer de extensie vanuit de Chrome Web Store en maak hem vast via het puzzelstukje-menu, zodat hij in de werkbalk blijft staan. Hij wordt automatisch bijgewerkt.

Toevoegen aan Chrome

Voor Android Android 11+

Een browser met de wallet ingebouwd. Typ een site en je krijgt Plain Wallet, met dezelfde goedkeuringen als de extensie. Geef de sites die je gebruikt een ster om ze bovenaan de wallet te houden, en ontgrendel desgewenst met je vingerafdruk.

Voor Mac en Safari macOS 14+ · in beoordeling bij de App Store

Eén app, twee manieren om hem te gebruiken: de wallet in een eigen venster en de Plain Wallet-extensie voor Safari, die dezelfde wallet delen. Open na het installeren Safari → Instellingen → Extensies, schakel Plain Wallet in en sta toe dat de extensie op websites werkt. Sites krijgen hem dan als hun wallet, met dezelfde goedkeuringen als de Chrome-extensie. Hij vergrendelt zodra je Mac in slaap valt of het scherm vergrendelt.

Voor Firefox ook LibreWolf · add-on in beoordeling

Plain Wallet wacht op beoordeling bij Firefox Add-ons. Tot het zover is, bouw je hem zelf en laad je hem tijdelijk via about:debugging. In LibreWolf of Firefox Developer Edition/Nightly kun je ook xpinstall.signatures.required uitschakelen en de zip openen nadat je hem hebt hernoemd naar .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Voor AI-agents eerst nalezen

Plak dit in Claude Code, Codex, Cursor of een andere agent die een shell kan draaien.

Installeer de browserextensie Plain Wallet voor me vanaf https://github.com/backmeupplz/plainwallet, maar bekijk de code eerst voordat je iets installeert of bouwt.

1. Clone de repo. Draai nog geen npm install: afhankelijkheden hebben installatiescripts.
2. Lees alle broncode: entrypoints/, lib/, wxt.config.ts, package.json en package-lock.json. Het zijn zo'n 2.850 regels TypeScript.
3. Zoek naar alles wat herstelzinnen of privésleutels kan lekken, gegevens kan versturen naar een andere plek dan de RPC die de gebruiker heeft gekozen, de versleuteling van de vault kan verzwakken, of kan ondertekenen zonder uitdrukkelijke goedkeuring. Controleer de afhankelijkheden op alles wat onverwacht is.
4. Meld wat je hebt gevonden, met verwijzingen naar bestand en regel. Stop en vraag het me als iets verdacht is.
5. Als alles in orde is: npm ci && npm test && npm run build
6. Vertel me hoe ik hem moet laden: in Chrome, chrome://extensions → Developer mode → Load unpacked → .output/chrome-mv3. Bouw voor Firefox met npx wxt zip -b firefox --mv3 en volg de README.

Voor mensen

Of bouw de extensie zelf uit de broncode, voor Chrome, Brave, Edge en andere Chromium-browsers, of voor Firefox.

  1. Clonen en bouwen:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Open chrome://extensions, schakel Ontwikkelaarsmodus in, klik op Uitgepakte extensie laden en kies .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3 en laad hem daarna zoals hierboven beschreven.

Niet geaudit. Bewaar er geen geld in dat je niet kunt missen.

Wachtwoord vergeten?

Het is niet te herstellen: de wallet is op je apparaat ermee versleuteld en niemand anders heeft een kopie. Reset de wallet vanaf het ontgrendelscherm, importeer daarna je herstelzin of privésleutel opnieuw en kies een nieuw wachtwoord.

Herstelzin kwijt?

Zolang de wallet nog te ontgrendelen is, exporteer je de herstelzin in Instellingen met je wachtwoord en schrijf je hem op. Zonder herstelzin en wachtwoord kan niemand de wallet herstellen, ook wij niet.
