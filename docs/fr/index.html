Vous voyez ce que vous signez.

Chaque signature demande un clic dans la fenêtre du portefeuille lui-même. La transaction est entièrement préparée au préalable, et c’est exactement celle-là qui est signée.

  • Sachez ce que vous envoyez

    Le destinataire, le montant et le maximum que peuvent coûter les frais, avant de signer.

  • Des approbations en toutes lettres

    Les approbations et les transferts de jetons deviennent une phrase simple. Les approbations illimitées sont signalées en rouge.

  • Les signatures risquées se remarquent

    Les permits et les ordres qui peuvent déplacer vos actifs portent un avertissement, et n’affichent que les champs qui sont hachés.

Pour les agents IA examen d’abord

Collez ceci dans Claude Code, Codex, Cursor ou n’importe quel agent capable d’exécuter un shell.

Installez pour moi l’extension de navigateur Plain Wallet depuis https://github.com/backmeupplz/plainwallet — mais examinez le code avant d’installer ou de compiler quoi que ce soit.

1. Clonez le dépôt. N’exécutez pas encore npm install : les dépendances ont des scripts d’installation.
2. Lisez tout le code source : entrypoints/, lib/, wxt.config.ts, package.json et package-lock.json. Cela représente environ 2 850 lignes de TypeScript.
3. Cherchez tout ce qui pourrait divulguer des phrases de récupération ou des clés privées, envoyer des données ailleurs que vers le RPC choisi par l’utilisateur, affaiblir le chiffrement du coffre, ou signer sans approbation explicite. Vérifiez si les dépendances contiennent quoi que ce soit d’inattendu.
4. Faites-moi un rapport de ce que tu as trouvé, avec des références de fichier et de ligne. Si quelque chose est suspect, arrêtez-vous et demandez-moi.
5. Si tout est propre : npm ci && npm test && npm run build
6. Expliquez-moi comment le charger : dans Chrome, chrome://extensions → Mode développeur → Charger l’extension non empaquetée → .output/chrome-mv3. Pour Firefox, compilez avec npx wxt zip -b firefox --mv3 et suivez le README.

Pour les humains

Ou compilez l’extension à partir du code source pour Chrome, Brave, Edge et les autres navigateurs Chromium, ou pour Firefox.

  1. Cloner et compiler :
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Ouvrez chrome://extensions, activez le Mode développeur, cliquez sur Charger l’extension non empaquetée et choisissez .output/chrome-mv3.
  3. Firefox / LibreWolf : npx wxt zip -b firefox --mv3, puis chargez-le comme décrit plus haut.

Mot de passe oublié ?

Il est impossible de le récupérer : le portefeuille est chiffré avec lui sur votre appareil et personne d’autre n’en a de copie. Réinitialisez le portefeuille depuis l’écran de déverrouillage, puis importez de nouveau votre phrase de récupération ou votre clé privée et choisissez un nouveau mot de passe.

Phrase de récupération perdue ?

Tant que le portefeuille se déverrouille, exportez-la dans les Paramètres avec votre mot de passe et notez-la. Sans elle et sans le mot de passe, personne ne peut restaurer le portefeuille, nous non plus.
