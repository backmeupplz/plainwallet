適用於 Mac 與 Safari macOS 14 以上 · App Store 審核中

一個 App，兩種使用方式：錢包在自己的視窗中運作，以及供 Safari 使用的 Plain Wallet 擴充功能，兩者共用同一個錢包。安裝後，開啟 Safari → 設定 → 擴充功能，開啟 Plain Wallet 並允許它在網站上執行；網站隨即會把它當作錢包，核准方式與 Chrome 擴充功能相同。Mac 進入睡眠或鎖定螢幕時，它也會跟著鎖定。

適用於 AI 代理 請先審閱程式碼

將這段文字貼到 Claude Code、Codex、Cursor，或任何能執行 shell 的代理中。

請幫我安裝 https://github.com/backmeupplz/plainwallet 的 Plain Wallet 瀏覽器擴充功能，但在安裝或建置任何東西之前，請先審閱程式碼。

1. 複製（clone）這個儲存庫。先不要執行 npm install：相依套件含有安裝腳本。
2. 讀完所有原始碼：entrypoints/、lib/、wxt.config.ts、package.json 和 package-lock.json。總共約 2,850 行 TypeScript。
3. 檢查是否有任何可能外洩助記詞或私鑰、把資料送到使用者所選 RPC 以外的地方、削弱保險庫加密，或未經明確核准就簽署的程式碼。也請檢查相依套件中有沒有任何非預期的內容。
4. 回報您的發現，並附上檔案與行號。如果有任何可疑之處，請停下來問我。
5. 如果沒有問題：npm ci && npm test && npm run build
6. 告訴我如何載入：在 Chrome 中，依序前往 chrome://extensions → 開發人員模式 → 載入未封裝項目 → .output/chrome-mv3。Firefox 則請用 npx wxt zip -b firefox --mv3 建置，並依照 README 操作。

給自己動手的人

也可以從原始碼自行建置擴充功能，支援 Chrome、Brave、Edge 與其他 Chromium 瀏覽器，以及 Firefox。

  1. 複製並建置：
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. 開啟 chrome://extensions，開啟開發人員模式，點擊載入未封裝項目，然後選擇 .output/chrome-mv3。
  3. Firefox / LibreWolf：執行 npx wxt zip -b firefox --mv3，再依上方說明載入。

忘記密碼了？

密碼無法找回：錢包是在您的裝置上以密碼加密的，沒有其他人持有副本。請在解鎖畫面重設錢包，再重新匯入您的助記詞或私鑰，並設定新密碼。

弄丟助記詞了？

只要錢包仍能解鎖，就請在「設定」中輸入密碼匯出助記詞，並抄寫下來。沒有助記詞和密碼，任何人都無法還原錢包，包括我們。
