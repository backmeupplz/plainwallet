Wei to ETH and gwei converter

Type an amount in any Ethereum unit and see it in all the others, worked out with integers so no digit is rounded. Nothing you type leaves this page.

How the conversion works

Everything on the chain is counted in wei, the smallest unit. One ether is 1018 wei and one gwei is 109 wei, so converting is moving a decimal point. This page reads what you type as a decimal string, turns it into a whole number of wei with BigInt, and prints each unit by placing the point in that whole number. It never uses floating-point numbers, which cannot hold 18 decimal places: in JavaScript, 0.1 + 0.2 is already 0.30000000000000004.

An amount with more decimals than its unit allows, such as 0.5 wei, is not a whole number of wei and is refused rather than rounded. Commas, spaces and underscores in the number are ignored.

Names: kwei is 103 wei (babbage), mwei is 106 (lovelace), szabo is 1012 and finney is 1015. Wallets and block explorers mostly show gwei for gas prices and ETH for balances.

Check an address checksum

An Ethereum address is 40 hex digits. EIP-55 spells some of its letters in capitals, chosen by the Keccak-256 hash of the lowercase address, so a mistyped character is very likely to be caught. Paste an address to see its correct form and whether yours matches.

An all-lowercase or all-uppercase address carries no checksum, so it is reported as unchecked and the checksummed form is shown for you to copy. The hash runs in your browser too.
