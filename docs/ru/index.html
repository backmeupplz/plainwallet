Вы видите, что подписываете.

Каждая подпись требует нажатия в отдельном окне самого кошелька. Транзакция сначала полностью готовится, и подписывается именно она.

  • Понятно, что вы отправляете

    Получатель, сумма и максимальная комиссия показаны до подписи.

  • Одобрения простыми словами

    Одобрения токенов и переводы записываются обычным предложением. Неограниченные выделены красным.

  • Опасные подписи заметны сразу

    Разрешения (permit) и ордера, которые могут переместить ваши активы, сопровождаются предупреждением и показывают только те поля, которые попадают в хеш.

Установка

Не доверяйте на слово, а проверьте. Именно для этого кошелёк сделан таким маленьким.

Для Chrome а также Brave и Edge

Установите кошелёк из Chrome Web Store, затем закрепите его в меню с пазлом, чтобы он оставался на панели инструментов. Обновляется автоматически.

Для Android Android 11+

Браузер со встроенным кошельком. Введите адрес сайта, и он получит Plain Wallet с теми же одобрениями, что и в расширении. Добавляйте нужные сайты в избранное, чтобы они были над кошельком, и при желании разблокируйте его отпечатком пальца.

Для Mac и Safari macOS 14+ · на проверке в App Store

Одно приложение, два способа использования: кошелёк в отдельном окне и расширение Plain Wallet для Safari, работающее с тем же кошельком. После установки откройте Safari → Настройки → Расширения, включите Plain Wallet и разрешите ему работать на сайтах; тогда сайты будут получать его как свой кошелёк, с теми же одобрениями, что и в расширении для Chrome. Он блокируется, когда Mac засыпает или блокирует экран.

Для Firefox а также LibreWolf · дополнение на проверке

Plain Wallet ожидает проверки в Firefox Add-ons. Пока его нет в каталоге, соберите его сами и загрузите временно через about:debugging, либо в LibreWolf или Firefox Developer Edition/Nightly отключите xpinstall.signatures.required и откройте zip-архив, переименованный в .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Для ИИ-агентов сначала проверка кода

Вставьте этот текст в Claude Code, Codex, Cursor или любого агента, который умеет работать в командной строке.

Установи для меня браузерное расширение Plain Wallet из https://github.com/backmeupplz/plainwallet, но сначала проверь код, а уже потом что-либо устанавливай или собирай.

1. Клонируй репозиторий. Пока не запускай npm install: у зависимостей есть скрипты установки.
2. Прочитай весь исходный код: entrypoints/, lib/, wxt.config.ts, package.json и package-lock.json. Это около 2850 строк на TypeScript.
3. Поищи всё, что способно раскрыть сид-фразы или приватные ключи, отправить данные куда-либо, кроме выбранного пользователем RPC, ослабить шифрование хранилища или подписать что-то без явного одобрения. Проверь зависимости на что-либо неожиданное.
4. Сообщи, что ты нашёл, со ссылками на файлы и строки. Если что-то вызывает подозрение, остановись и спроси меня.
5. Если всё чисто: npm ci && npm test && npm run build
6. Расскажи, как его загрузить: в Chrome — chrome://extensions → Режим разработчика → Загрузить распакованное расширение → .output/chrome-mv3. Для Firefox собери командой npx wxt zip -b firefox --mv3 и следуй README.

Для людей

Или соберите расширение из исходного кода для Chrome, Brave, Edge и других браузеров на Chromium либо для Firefox.

  1. Клонируйте и соберите:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Откройте chrome://extensions, включите Режим разработчика, нажмите Загрузить распакованное расширение и выберите .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, затем загрузите его, как описано выше.

Забыли пароль?

Восстановить его нельзя: кошелёк зашифрован им на вашем устройстве, и ни у кого другого копии нет. Сбросьте кошелёк на экране разблокировки, затем снова импортируйте сид-фразу или приватный ключ и задайте новый пароль.

Потеряли сид-фразу?

Пока кошелёк ещё разблокируется, экспортируйте её в Настройках с помощью пароля и запишите. Без неё и пароля никто не сможет восстановить кошелёк, в том числе и мы.
