Du ser vad du signerar.

Varje signering kräver ett klick i plånbokens eget fönster. Transaktionen förbereds helt först, och exakt den signeras.

  • Du vet vad du skickar

    Mottagare, belopp och högsta möjliga avgift, innan du signerar.

  • Godkännanden, utskrivna

    Godkännanden och överföringar av token blir en vanlig mening. Obegränsade markeras med rött.

  • Riskfyllda signaturer syns tydligt

    Permits och ordrar som kan flytta dina tillgångar får en varning som bara visar de fält som hashas.

För Mac och Safari macOS 14+ · Mac App Store

En app, två sätt att använda den: plånboken i ett eget fönster och tillägget Plain Wallet för Safari, som delar samma plånbok. Öppna Safari → Inställningar → Tillägg efter installationen, aktivera Plain Wallet och tillåt det på webbplatser. För Firefox LibreWolf också · tillägget granskas

Plain Wallet väntar på granskning hos Firefox Add-ons. Tills det finns i butiken kan du bygga det själv och sedan läsa in det tillfälligt från about:debugging, eller i LibreWolf eller Firefox Developer Edition/Nightly stänga av xpinstall.signatures.required och öppna zip-filen omdöpt till .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

För AI-agenter granska först

Klistra in det här i Claude Code, Codex, Cursor eller någon annan agent som kan köra ett skal.

Installera webbläsartillägget Plain Wallet åt mig från https://github.com/backmeupplz/plainwallet, men granska koden innan du installerar eller bygger något.

1. Klona repot. Kör inte npm install än: beroendena har installationsskript.
2. Läs all källkod: entrypoints/, lib/, wxt.config.ts, package.json och package-lock.json. Det är cirka 2 850 rader TypeScript.
3. Leta efter allt som kan läcka återställningsfraser eller privata nycklar, skicka data till något annat än användarens valda RPC, försvaga valvets kryptering eller signera utan ett uttryckligt godkännande. Kontrollera beroendena efter oväntade saker.
4. Rapportera vad du hittade, med fil- och radhänvisningar. Om något verkar misstänkt, stanna och fråga mig.
5. Om allt är rent: npm ci && npm test && npm run build
6. Berätta hur jag läser in det: i Chrome, chrome://extensions → Utvecklarläge → Läs in okomprimerat tillägg → .output/chrome-mv3. För Firefox, bygg med npx wxt zip -b firefox --mv3 och följ README.

För människor

Eller bygg tillägget från källkoden för Chrome, Brave, Edge och andra Chromium-webbläsare, eller för Firefox.

  1. Klona och bygg:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Öppna chrome://extensions, aktivera Utvecklarläge, klicka på Läs in okomprimerat tillägg och välj .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, och läs sedan in det enligt beskrivningen ovan.

Inte granskad. Förvara inte mer i den än du har råd att förlora.

Support

Mejla frågor till plainwallet@borodutch.com, eller lägg buggrapporter och önskemål om funktioner i GitHubs ärendehantering. Utvecklaren svarar på båda. Skriv aldrig ditt lösenord, din återställningsfras eller din privata nyckel där, eller någon annanstans.

Har du glömt ditt lösenord?

Det går inte att återställa: plånboken är krypterad med det på din enhet och ingen annan har en kopia. Återställ plånboken från upplåsningsskärmen, importera sedan din återställningsfras eller privata nyckel igen och välj ett nytt lösenord.

Har du tappat bort din återställningsfras?

Så länge plånboken går att låsa upp kan du exportera den under Inställningar med ditt lösenord och skriva ner den. Utan den och lösenordet kan ingen återställa plånboken, inte heller vi.
