आप जो साइन करते हैं, वह आपको दिखता है।

हर साइन के लिए वॉलेट की अपनी विंडो में क्लिक करना पड़ता है। लेन-देन पहले पूरी तरह तैयार होता है, और ठीक वही साइन किया जाता है।

  • जानें कि आप क्या भेज रहे हैं

    साइन करने से पहले पाने वाला, राशि और फ़ीस में लग सकने वाली अधिकतम रकम आपके सामने होती है।

  • मंज़ूरियाँ, सीधे शब्दों में

    टोकन की मंज़ूरियाँ और ट्रांसफ़र एक सादे वाक्य में बदल जाते हैं। असीमित मंज़ूरियों को लाल रंग से चिह्नित किया जाता है।

  • जोखिम भरे साइन अलग से दिखते हैं

    जो परमिट और ऑर्डर आपकी संपत्ति को दूसरे के हाथ में भेज सकते हैं, उन पर चेतावनी दिखती है, और उसमें केवल वही फ़ील्ड होते हैं जिनका हैश बनता है।

Mac और Safari के लिए macOS 14+ · Mac App Store

एक ऐप, इस्तेमाल के दो तरीके: वॉलेट अपनी अलग विंडो में, और Safari के लिए Plain Wallet एक्सटेंशन, दोनों एक ही वॉलेट साझा करते हैं। इंस्टॉल करने के बाद Safari → सेटिंग → एक्सटेंशन खोलें, Plain Wallet चालू करें और उसे वेबसाइटों पर चलने की अनुमति दें; तब साइटों को यह उनके वॉलेट के रूप में मिलता है, उन्हीं मंज़ूरियों के साथ जो Chrome एक्सटेंशन में हैं। जब आपका Mac सो जाता है या स्क्रीन लॉक होती है, तो यह लॉक हो जाता है।

Firefox के लिए LibreWolf में भी · ऐड-ऑन समीक्षा में

Plain Wallet Firefox Add-ons पर समीक्षा के इंतज़ार में है। जब तक यह सूची में नहीं आता, इसे खुद बनाएँ और about:debugging से अस्थायी रूप से लोड करें, या LibreWolf या Firefox Developer Edition/Nightly में xpinstall.signatures.required बंद करके .xpi नाम की हुई zip फ़ाइल खोलें।

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

AI एजेंट के लिए पहले समीक्षा करें

इसे Claude Code, Codex, Cursor या किसी भी ऐसे एजेंट में पेस्ट करें जो शेल चला सकता हो।

मेरे लिए https://github.com/backmeupplz/plainwallet से Plain Wallet ब्राउज़र एक्सटेंशन इंस्टॉल करो, लेकिन कुछ भी इंस्टॉल या बिल्ड करने से पहले कोड की समीक्षा करो।

1. रेपो क्लोन करो। अभी npm install मत चलाओ: डिपेंडेंसी में इंस्टॉल स्क्रिप्ट होती हैं।
2. पूरा सोर्स पढ़ो: entrypoints/, lib/, wxt.config.ts, package.json और package-lock.json। यह TypeScript की लगभग 2,850 लाइनें हैं।
3. ऐसा कुछ ढूँढो जिससे सीड फ़्रेज़ या प्राइवेट की लीक हो सकती हों, यूज़र के चुने RPC के अलावा कहीं और डेटा जा सकता हो, वॉल्ट का एन्क्रिप्शन कमज़ोर होता हो, या बिना साफ़ मंज़ूरी के साइन हो सकता हो। डिपेंडेंसी में भी कुछ अनपेक्षित हो तो देखो।
4. जो मिला, वह फ़ाइल और लाइन के हवाले के साथ बताओ। अगर कुछ भी संदिग्ध लगे, तो रुक जाओ और मुझसे पूछो।
5. अगर सब ठीक है: npm ci && npm test && npm run build
6. मुझे बताओ कि इसे कैसे लोड करना है: Chrome में chrome://extensions → Developer mode → Load unpacked → .output/chrome-mv3. Firefox के लिए npx wxt zip -b firefox --mv3 से बिल्ड करो और README का तरीका अपनाओ।

इंसानों के लिए

या एक्सटेंशन को सोर्स से खुद बनाएँ: Chrome, Brave, Edge और दूसरे Chromium ब्राउज़रों के लिए, या Firefox के लिए।

  1. क्लोन करें और बनाएँ:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. chrome://extensions खोलें, Developer mode चालू करें, Load unpacked पर क्लिक करें और .output/chrome-mv3 चुनें।
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, फिर इसे ऊपर बताए तरीके से लोड करें।

ऑडिट नहीं हुआ है। इसमें उतनी ही रकम रखें जिसे खोना आप सह सकते हैं।

पासवर्ड भूल गए?

इसे वापस नहीं पाया जा सकता: वॉलेट आपके डिवाइस पर इसी से एन्क्रिप्ट होता है और इसकी कॉपी किसी और के पास नहीं है। अनलॉक स्क्रीन से वॉलेट रीसेट करें, फिर अपना सीड फ़्रेज़ या प्राइवेट की दोबारा इंपोर्ट करें और नया पासवर्ड चुनें।

सीड फ़्रेज़ खो गया?

जब तक वॉलेट अनलॉक हो रहा है, सेटिंग में अपने पासवर्ड से उसे एक्सपोर्ट करें और लिखकर रख लें। उसके और पासवर्ड के बिना कोई भी वॉलेट को वापस नहीं ला सकता, हम भी नहीं।
