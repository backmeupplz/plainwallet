Você vê o que assina.

Toda assinatura exige um clique na janela da própria carteira. A transação é totalmente preparada antes, e é exatamente ela que é assinada.

  • Saiba o que você envia

    Destinatário, valor e o máximo que a taxa pode custar, antes de você assinar.

  • Aprovações explicadas

    Aprovações e transferências de tokens viram uma frase simples. As ilimitadas são marcadas em vermelho.

  • Assinaturas de risco chamam atenção

    Permits e ordens que podem movimentar seus ativos trazem um aviso e mostram apenas os campos que entram no hash.

Para Mac e Safari macOS 14+ · em análise na App Store

Um app, dois jeitos de usar: a carteira em uma janela própria e a extensão do Plain Wallet para o Safari, compartilhando a mesma carteira. Depois de instalar, abra Safari → Ajustes → Extensões, ative o Plain Wallet e permita o uso em sites; os sites passam a recebê-lo como carteira, com as mesmas aprovações da extensão do Chrome. Ele é bloqueado quando o Mac entra em repouso ou bloqueia a tela.

Para Firefox LibreWolf também · add-on em análise

O Plain Wallet está aguardando análise no Firefox Add-ons. Até que ele seja listado, compile-o você mesmo e carregue-o temporariamente em about:debugging ou, no LibreWolf ou no Firefox Developer Edition/Nightly, desative xpinstall.signatures.required e abra o zip renomeado para .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Para agentes de IA revise primeiro

Cole isto no Claude Code, no Codex, no Cursor ou em qualquer agente que consiga executar um shell.

Instale para mim a extensão de navegador Plain Wallet a partir de https://github.com/backmeupplz/plainwallet, mas revise o código antes de instalar ou compilar qualquer coisa.

1. Clone o repositório. Não execute npm install ainda: as dependências têm scripts de instalação.
2. Leia todo o código-fonte: entrypoints/, lib/, wxt.config.ts, package.json e package-lock.json. São cerca de 2.850 linhas de TypeScript.
3. Procure qualquer coisa que possa vazar frases de recuperação ou chaves privadas, enviar dados para qualquer lugar além do RPC escolhido pelo usuário, enfraquecer a criptografia do cofre ou assinar sem uma aprovação explícita. Verifique se as dependências têm algo inesperado.
4. Relate o que encontrou, com referências de arquivo e linha. Se algo parecer suspeito, pare e me pergunte.
5. Se estiver tudo limpo: npm ci && npm test && npm run build
6. Diga como carregá-la: no Chrome, chrome://extensions → Modo do desenvolvedor → Carregar sem compactação → .output/chrome-mv3. Para o Firefox, compile com npx wxt zip -b firefox --mv3 e siga o README.

Para pessoas

Ou compile a extensão a partir do código-fonte para Chrome, Brave, Edge e outros navegadores Chromium, ou para Firefox.

  1. Clonar e compilar:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Abra chrome://extensions, ative o Modo do desenvolvedor, clique em Carregar sem compactação e escolha .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3 e depois carregue como descrito acima.

Sem auditoria. Não guarde nela fundos que você não possa perder.

Esqueceu a senha?

Ela não pode ser recuperada: a carteira é criptografada com ela no seu dispositivo e ninguém mais tem uma cópia. Redefina a carteira na tela de desbloqueio, importe de novo sua frase de recuperação ou chave privada e escolha uma nova senha.

Perdeu a frase de recuperação?

Enquanto a carteira ainda desbloqueia, exporte a frase em Configurações com sua senha e anote-a. Sem ela e sem a senha, ninguém consegue restaurar a carteira, nem nós.
