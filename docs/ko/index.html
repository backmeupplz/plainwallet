믿지 말고 직접 확인하세요. 코드를 작게 유지하는 이유가 바로 그것입니다.

Chrome용 Brave, Edge에서도 사용 가능

Chrome 웹 스토어에서 설치한 다음, 퍼즐 조각 메뉴에서 고정하면 도구 모음에 계속 표시됩니다. 업데이트는 자동으로 됩니다.

Chrome에 추가

Android용 Android 11 이상

지갑이 내장된 브라우저입니다. 사이트 주소를 입력하면 해당 사이트에 Plain Wallet이 연결되며, 승인 방식은 확장 프로그램과 같습니다. 자주 쓰는 사이트를 즐겨찾기에 추가하면 지갑 위쪽에 고정되고, 원하면 지문으로 잠금을 해제할 수 있습니다.

Google Play에서 받기 또는 APK 다운로드 확장 프로그램과 다른 점

Mac 및 Safari용 macOS 14 이상 · Mac App Store

앱 하나로 두 가지 방식을 쓸 수 있습니다. 자체 창에서 쓰는 지갑과, 같은 지갑을 공유하는 Safari용 Plain Wallet 확장 프로그램입니다. 설치한 뒤 Safari → 설정 → 확장 프로그램에서 Plain Wallet을 켜고 웹사이트에서 사용하도록 허용하면, 사이트에서 이 지갑을 쓸 수 있고 승인 방식은 Chrome 확장 프로그램과 같습니다. Mac이 잠자기 상태가 되거나 화면이 잠기면 지갑도 잠깁니다.

iPhone용 iOS 18 이상 · App Store

Android 앱과 같습니다. 지갑이 내장된 브라우저로, 사이트 주소를 입력하면 해당 사이트에 Plain Wallet이 연결됩니다. 자주 쓰는 사이트를 즐겨찾기에 추가할 수 있고, 원하면 Face ID나 Touch ID로 잠금을 해제할 수 있습니다.

Firefox용 LibreWolf에서도 사용 가능 · 부가 기능 심사 중

Plain Wallet은 Firefox Add-ons에서 심사를 기다리고 있습니다. 등록되기 전에는 직접 빌드한 다음 about:debugging에서 임시로 불러오거나, LibreWolf 또는 Firefox Developer Edition/Nightly에서 xpinstall.signatures.required를 끄고 zip 파일의 이름을 .xpi로 바꿔 여세요.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

AI 에이전트용 먼저 코드 검토

Claude Code, Codex, Cursor 또는 셸을 실행할 수 있는 에이전트에 아래 내용을 붙여 넣으세요.

https://github.com/backmeupplz/plainwallet 에 있는 Plain Wallet 브라우저 확장 프로그램을 나 대신 설치해 줘. 단, 설치나 빌드를 하기 전에 먼저 코드를 검토해 줘.

1. 저장소를 clone해. 아직 npm install은 실행하지 마. 의존성에 install 스크립트가 있어.
2. 소스 전체를 읽어: entrypoints/, lib/, wxt.config.ts, package.json, package-lock.json. TypeScript 약 2850줄이야.
3. 시드 구문이나 개인 키를 유출할 수 있는 부분, 사용자가 고른 RPC 외의 곳으로 데이터를 보내는 부분, 금고 암호화를 약하게 만드는 부분, 명시적인 승인 없이 서명하는 부분이 있는지 찾아봐. 의존성에도 예상 밖의 것이 없는지 확인해.
4. 찾은 내용을 파일과 줄 번호와 함께 보고해. 수상한 점이 있으면 멈추고 나에게 물어봐.
5. 문제가 없으면: npm ci && npm test && npm run build
6. 불러오는 방법을 알려 줘: Chrome에서는 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다 → .output/chrome-mv3. Firefox는 npx wxt zip -b firefox --mv3 로 빌드하고 README를 따라 해.

직접 설치하려는 분께

또는 Chrome, Brave, Edge 등 Chromium 기반 브라우저나 Firefox용 확장 프로그램을 소스에서 직접 빌드할 수 있습니다.

  1. 복제하고 빌드하기:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. chrome://extensions를 열고 개발자 모드를 켠 다음 압축해제된 확장 프로그램을 로드합니다를 클릭하고 .output/chrome-mv3를 선택하세요.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3를 실행한 다음 위에 설명한 대로 불러오세요.

감사를 받지 않았습니다. 잃어도 괜찮은 금액만 보관하세요.

비밀번호를 잊으셨나요?

복구할 수 없습니다. 지갑은 기기에서 그 비밀번호로 암호화되며 사본을 가진 사람은 아무도 없습니다. 잠금 해제 화면에서 지갑을 초기화한 다음, 시드 구문이나 개인 키를 다시 가져오고 새 비밀번호를 정하세요.

시드 구문을 잃어버리셨나요?

지갑이 아직 잠금 해제되는 동안 설정에서 비밀번호로 시드 구문을 내보내 적어 두세요. 시드 구문과 비밀번호가 없으면 우리를 포함해 누구도 지갑을 복원할 수 없습니다.
