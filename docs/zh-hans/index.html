  • 清楚知道发送了什么

一款内置钱包的浏览器。输入网址，网站就会获得 Plain Wallet，批准流程与扩展程序相同。给常用网站加星标，它们就会固定在钱包上方，您也可以选择用指纹解锁。

一个应用，两种用法：钱包在自己的窗口中运行，同时还有适用于 Safari 的 Plain Wallet 扩展程序，两者共用同一个钱包。安装后，打开 Safari → 设置 → 扩展，开启 Plain Wallet 并允许它在网站上使用；之后网站会把它当作自己的钱包，批准流程与 Chrome 扩展程序相同。Mac 进入睡眠或锁定屏幕时，它也会随之锁定。

适用于手动安装

也可以从源代码构建扩展程序，适用于 Chrome、Brave、Edge 等 Chromium 浏览器，或 Firefox。

  1. 克隆并构建：
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. 打开 chrome://extensions，开启开发者模式，点击加载已解压的扩展程序，然后选择 .output/chrome-mv3。
  3. Firefox / LibreWolf：运行 npx wxt zip -b firefox --mv3，然后按上文所述加载。

发送邮件至 plainwallet@borodutch.com 提问或报告错误 浏览现有问题

忘记密码了？

密码无法找回：钱包在您的设备上用它加密，其他任何人都没有副本。请在解锁界面重置钱包，然后重新导入助记词或私钥，并设置新密码。

丢失了助记词？

只要钱包还能解锁，就请在“设置”中输入密码导出助记词，并抄写下来。没有助记词和密码，任何人都无法恢复这个钱包，我们也不例外。
