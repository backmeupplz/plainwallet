Un wallet che puoi leggere.

Un wallet EVM molto minimale per Chrome, Firefox, Safari, Android, iPhone e Mac. Circa 2.850 righe di TypeScript, abbastanza poche da leggerle in una serata, o da far leggere al tuo agente in un minuto.

  • 3 dipendenze runtime
  • nessun server
  • nessun analytics

Vedi cosa firmi.

Ogni firma richiede un clic nella finestra del wallet stesso. La transazione viene prima preparata per intero e viene firmata esattamente quella.

  • Sai cosa invii

    Destinatario, importo e la commissione massima che può costare, prima di firmare.

  • Approvazioni in chiaro

    Le approvazioni e i trasferimenti di token diventano una frase semplice. Quelle illimitate sono segnalate in rosso.

  • Le firme rischiose si notano

    I permit e gli ordini che possono spostare i tuoi asset mostrano un avviso, con solo i campi che vengono sottoposti a hash.

Per Firefox anche LibreWolf · componente aggiuntivo in revisione

Plain Wallet è in attesa di revisione su Firefox Add-ons. Finché non è pubblicato, compilalo tu stesso e caricalo temporaneamente da about:debugging; in LibreWolf o in Firefox Developer Edition/Nightly, invece, disattiva xpinstall.signatures.required e apri lo zip rinominato in .xpi.

Per gli agenti IA prima la revisione

Incolla questo testo in Claude Code, Codex, Cursor o in qualsiasi agente in grado di eseguire una shell.

Installa per me l'estensione del browser Plain Wallet da https://github.com/backmeupplz/plainwallet, ma esamina il codice prima di installare o compilare qualsiasi cosa.

1. Clona il repository. Non eseguire ancora npm install: le dipendenze hanno script di installazione.
2. Leggi tutto il sorgente: entrypoints/, lib/, wxt.config.ts, package.json e package-lock.json. Sono circa 2.850 righe di TypeScript.
3. Cerca qualsiasi cosa che possa far trapelare frasi di recupero o chiavi private, inviare dati a qualcosa di diverso dall'RPC scelto dall'utente, indebolire la cifratura del vault o firmare senza un'approvazione esplicita. Controlla le dipendenze alla ricerca di qualcosa di inatteso.
4. Riferisci cosa hai trovato, con riferimenti a file e righe. Se c'è qualcosa di sospetto, fermati e chiedimelo.
5. Se è tutto pulito: npm ci && npm test && npm run build
6. Spiegami come caricarla: in Chrome, chrome://extensions → Modalità sviluppatore → Carica estensione non pacchettizzata → .output/chrome-mv3. Per Firefox, compila con npx wxt zip -b firefox --mv3 e segui il README.

Per le persone

Oppure compila l'estensione dai sorgenti per Chrome, Brave, Edge e altri browser Chromium, oppure per Firefox.

  1. Clona e compila:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Apri chrome://extensions, attiva Modalità sviluppatore, fai clic su Carica estensione non pacchettizzata e scegli .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, poi caricalo come descritto sopra.

Non sottoposto ad audit. Non tenerci fondi che non puoi permetterti di perdere.

Assistenza

Scrivi le tue domande a plainwallet@borodutch.com, oppure segnala bug e richieste di funzionalità nell'issue tracker di GitHub; lo sviluppatore risponde a entrambi. Non pubblicare mai lì, né altrove, la tua password, la frase di recupero o la chiave privata.

Hai dimenticato la password?

Non si può recuperare: il wallet è cifrato con quella password sul tuo dispositivo e nessun altro ne ha una copia. Reimposta il wallet dalla schermata di sblocco, poi importa di nuovo la frase di recupero o la chiave privata e scegli una nuova password.

Hai perso la frase di recupero?

Finché il wallet si sblocca ancora, esportala da Impostazioni con la tua password e scrivila su carta. Senza di essa e senza la password nessuno può ripristinare il wallet, noi compresi.
