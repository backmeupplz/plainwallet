BELUM DIAUDIThanya untuk dana kecil

Anda melihat apa yang Anda tanda tangani.

Setiap tanda tangan memerlukan satu klik di jendela milik dompet itu sendiri. Transaksi disiapkan lengkap terlebih dahulu, dan persis itulah yang ditandatangani.

  • Ketahui apa yang Anda kirim

    Penerima, jumlah, dan biaya tertinggi yang mungkin dikenakan, ditampilkan sebelum Anda menandatangani.

  • Persetujuan, dijelaskan dengan jelas

    Persetujuan token dan transfer diubah menjadi kalimat biasa. Persetujuan tanpa batas ditandai merah.

  • Tanda tangan berisiko menonjol

    Permit dan order yang dapat memindahkan aset Anda diberi peringatan, dengan hanya menampilkan kolom yang di-hash.

Untuk Firefox LibreWolf juga · add-on dalam peninjauan

Plain Wallet sedang menunggu peninjauan di Firefox Add-ons. Sebelum terdaftar di sana, build sendiri, lalu muat sementara dari about:debugging, atau di LibreWolf atau Firefox Developer Edition/Nightly nonaktifkan xpinstall.signatures.required dan buka file zip yang namanya diubah menjadi .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Untuk agen AI tinjau dulu

Tempel teks ini ke Claude Code, Codex, Cursor, atau agen apa pun yang dapat menjalankan shell.

Pasangkan ekstensi peramban Plain Wallet untuk saya dari https://github.com/backmeupplz/plainwallet — tetapi tinjau kodenya sebelum Anda memasang atau membuild apa pun.

1. Clone repo-nya. Jangan jalankan npm install dulu: dependensinya memiliki skrip instalasi.
2. Baca seluruh kode sumbernya: entrypoints/, lib/, wxt.config.ts, package.json, dan package-lock.json. Jumlahnya sekitar 2.850 baris TypeScript.
3. Cari apa pun yang dapat membocorkan frasa pemulihan atau kunci privat, mengirim data ke tempat selain RPC pilihan pengguna, melemahkan enkripsi vault, atau menandatangani tanpa persetujuan yang eksplisit. Periksa dependensinya untuk hal yang tidak terduga.
4. Laporkan temuan Anda, lengkap dengan rujukan file dan baris. Jika ada yang mencurigakan, berhenti dan tanyakan kepada saya.
5. Jika bersih: npm ci && npm test && npm run build
6. Beri tahu saya cara memuatnya: di Chrome, chrome://extensions → Developer mode → Load unpacked → .output/chrome-mv3. Untuk Firefox, build dengan npx wxt zip -b firefox --mv3 dan ikuti README.

Untuk manusia

Atau build ekstensi dari kode sumber untuk Chrome, Brave, Edge dan peramban Chromium lainnya, atau untuk Firefox.

  1. Clone dan build:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Buka chrome://extensions, aktifkan Developer mode, klik Load unpacked, lalu pilih .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, lalu muat seperti dijelaskan di atas.

Belum diaudit. Jangan simpan dana yang tidak sanggup Anda relakan hilang di dalamnya.

Lupa kata sandi?

Kata sandi tidak dapat dipulihkan: dompet dienkripsi dengannya di perangkat Anda dan tidak ada orang lain yang menyimpan salinannya. Setel ulang dompet dari layar buka kunci, lalu impor lagi frasa pemulihan atau kunci privat Anda dan pilih kata sandi baru.

Kehilangan frasa pemulihan?

Selama dompet masih bisa dibuka, ekspor frasa itu di Setelan dengan kata sandi Anda dan tuliskan. Tanpa frasa itu dan kata sandinya, tidak ada yang dapat memulihkan dompet, termasuk kami.
