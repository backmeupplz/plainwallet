กระเป๋าเงินที่คุณอ่านได้

กระเป๋าเงิน EVM แบบเรียบง่ายสุดๆ สำหรับ Chrome, Firefox, Safari, Android, iPhone และ Mac โค้ด TypeScript ราว 2,850 บรรทัด สั้นพอที่คุณจะอ่านจบในคืนเดียว หรือให้เอเจนต์ของคุณอ่านจบในหนึ่งนาที

  • ไลบรารีตอนรันไทม์ 3 ตัว
  • ไม่มีเซิร์ฟเวอร์
  • ไม่มีการวิเคราะห์ข้อมูลผู้ใช้
  • MIT
เพิ่มใน Chrome Android Mac และ Safari iPhone อ่านซอร์สโค้ด
ยังไม่ผ่านการตรวจสอบใช้กับเงินจำนวนน้อยเท่านั้น

คุณเห็นสิ่งที่คุณลงนาม

ทุกการลงนามต้องให้คุณกดยืนยันในหน้าต่างของกระเป๋าเงินเอง ธุรกรรมจะถูกเตรียมให้ครบถ้วนก่อน แล้วจึงลงนามตามนั้นทุกประการ

  • รู้ว่าคุณส่งอะไรไป

    ผู้รับ จำนวนเงิน และค่าธรรมเนียมสูงสุดที่อาจต้องจ่าย แสดงให้เห็นก่อนที่คุณจะลงนาม

  • การอนุมัติที่อ่านเข้าใจง่าย

    การอนุมัติโทเค็นและการโอนจะแสดงเป็นประโยคธรรมดา การอนุมัติแบบไม่จำกัดจะมีสีแดงกำกับ

  • ลายเซ็นที่เสี่ยงจะเด่นชัด

    Permit และคำสั่งซื้อขายที่ย้ายสินทรัพย์ของคุณได้จะมีคำเตือนกำกับ และแสดงเฉพาะฟิลด์ที่ถูกนำไปแฮช

ติดตั้ง

อย่าเพิ่งเชื่อ ให้ตรวจสอบด้วยตัวเอง นั่นคือเหตุผลที่เราทำให้มันเล็ก

สำหรับ Chrome ใช้กับ Brave และ Edge ได้ด้วย

ติดตั้งจาก Chrome Web Store แล้วปักหมุดจากเมนูรูปตัวต่อจิ๊กซอว์ เพื่อให้ปรากฏบนแถบเครื่องมือ ส่วนขยายจะอัปเดตเองโดยอัตโนมัติ

เพิ่มใน Chrome

สำหรับ Android Android 11 ขึ้นไป

เบราว์เซอร์ที่มีกระเป๋าเงินในตัว พิมพ์ชื่อเว็บไซต์แล้วเว็บไซต์นั้นจะได้ใช้ Plain Wallet พร้อมการอนุมัติแบบเดียวกับส่วนขยาย เพิ่มเว็บไซต์ที่คุณใช้ในรายการโปรดเพื่อเก็บไว้ด้านบนของกระเป๋าเงิน และเปิดใช้การปลดล็อกด้วยลายนิ้วมือได้หากต้องการ

รับจาก Google Play หรือดาวน์โหลด APK ต่างจากส่วนขยายอย่างไร

สำหรับ Mac และ Safari macOS 14 ขึ้นไป · อยู่ระหว่างการตรวจสอบของ App Store

แอปเดียว ใช้ได้สองแบบ คือกระเป๋าเงินในหน้าต่างของตัวเอง และส่วนขยาย Plain Wallet สำหรับ Safari ที่ใช้กระเป๋าเงินใบเดียวกัน หลังติดตั้งให้เปิด Safari → การตั้งค่า → ส่วนขยาย เปิด Plain Wallet และอนุญาตให้ใช้บนเว็บไซต์ จากนั้นเว็บไซต์จะได้ใช้ส่วนขยายนี้เป็นกระเป๋าเงิน พร้อมการอนุมัติแบบเดียวกับส่วนขยาย Chrome แอปจะล็อกเมื่อ Mac เข้าสู่โหมดสลีปหรือล็อกหน้าจอ

Mac App Store แอป Mac ทำงานอย่างไร

สำหรับ iPhone iOS 18 ขึ้นไป · อยู่ระหว่างการตรวจสอบของ App Store

เหมือนแอป Android คือเบราว์เซอร์ที่มีกระเป๋าเงินในตัว พิมพ์ชื่อเว็บไซต์แล้วเว็บไซต์นั้นจะได้ใช้ Plain Wallet เพิ่มเว็บไซต์ที่คุณใช้ในรายการโปรด และเปิดใช้การปลดล็อกด้วย Face ID หรือ Touch ID ได้หากต้องการ

App Store ต่างจากส่วนขยายอย่างไร

สำหรับ Firefox ใช้กับ LibreWolf ได้ด้วย · ส่วนเสริมอยู่ระหว่างการตรวจสอบ

Plain Wallet กำลังรอการตรวจสอบบน Firefox Add-ons ระหว่างที่ยังไม่ได้ขึ้นรายการ ให้สร้างเองก่อน แล้วโหลดแบบชั่วคราวจาก about:debugging หรือถ้าใช้ LibreWolf หรือ Firefox Developer Edition/Nightly ให้ปิด xpinstall.signatures.required แล้วเปิดไฟล์ zip ที่เปลี่ยนชื่อเป็น .xpi

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

สำหรับเอเจนต์ AI ตรวจสอบก่อน

วางข้อความนี้ลงใน Claude Code, Codex, Cursor หรือเอเจนต์ใดก็ได้ที่รันเชลล์ได้

ช่วยติดตั้งส่วนขยายเบราว์เซอร์ Plain Wallet ให้ฉันจาก https://github.com/backmeupplz/plainwallet แต่ให้ตรวจสอบโค้ดก่อนติดตั้งหรือสร้างอะไรทั้งนั้น

1. โคลนรีโป อย่าเพิ่งรัน npm install เพราะไลบรารีที่พึ่งพามีสคริปต์ติดตั้ง
2. อ่านซอร์สโค้ดทั้งหมด: entrypoints/, lib/, wxt.config.ts, package.json และ package-lock.json มี TypeScript ราว 2,850 บรรทัด
3. มองหาสิ่งที่อาจทำให้วลีกู้คืนหรือคีย์ส่วนตัวรั่วไหล ส่งข้อมูลไปที่อื่นนอกจาก RPC ที่ผู้ใช้เลือก ทำให้การเข้ารหัสของ vault อ่อนลง หรือลงนามโดยไม่มีการอนุมัติที่ชัดเจน ตรวจสอบไลบรารีที่พึ่งพาว่ามีอะไรที่ไม่คาดคิดหรือไม่
4. รายงานสิ่งที่พบ พร้อมอ้างอิงไฟล์และหมายเลขบรรทัด หากมีอะไรน่าสงสัย ให้หยุดและถามฉัน
5. ถ้าไม่มีปัญหา: npm ci && npm test && npm run build
6. บอกฉันว่าต้องโหลดอย่างไร: ใน Chrome ไปที่ chrome://extensions → Developer mode → Load unpacked → .output/chrome-mv3. สำหรับ Firefox ให้สร้างด้วย npx wxt zip -b firefox --mv3 แล้วทำตาม README

สำหรับคน

หรือจะสร้างส่วนขยายจากซอร์สโค้ดเองก็ได้ สำหรับ Chrome, Brave, Edge และเบราว์เซอร์ Chromium อื่นๆ หรือสำหรับ Firefox

  1. โคลนและสร้าง:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. เปิด chrome://extensions เปิด โหมดนักพัฒนาซอฟต์แวร์ คลิก โหลดส่วนขยายที่แกะแล้ว แล้วเลือก .output/chrome-mv3
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3 แล้วโหลดตามที่อธิบายไว้ข้างบน

ยังไม่ผ่านการตรวจสอบ อย่าเก็บเงินที่คุณเสียไม่ได้ไว้ในนี้

ลืมรหัสผ่าน?

กู้คืนไม่ได้ เพราะกระเป๋าเงินถูกเข้ารหัสด้วยรหัสผ่านนี้บนอุปกรณ์ของคุณ และไม่มีใครอื่นเก็บสำเนาไว้ ให้รีเซ็ตกระเป๋าเงินจากหน้าจอปลดล็อก แล้วนำเข้าวลีกู้คืนหรือคีย์ส่วนตัวของคุณอีกครั้ง และตั้งรหัสผ่านใหม่

วลีกู้คืนหาย?

ตราบใดที่กระเป๋าเงินยังปลดล็อกได้ ให้ส่งออกวลีนั้นในการตั้งค่าด้วยรหัสผ่านของคุณ แล้วจดไว้ หากไม่มีวลีกู้คืนและรหัสผ่าน จะไม่มีใครกู้คืนกระเป๋าเงินได้ รวมถึงเราด้วย
