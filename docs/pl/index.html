Widzisz, co podpisujesz.

Każdy podpis wymaga kliknięcia w oknie samego portfela. Transakcja jest najpierw w pełni przygotowana i podpisywana jest dokładnie ta, którą widzisz.

  • Wiesz, co wysyłasz

    Odbiorca, kwota i maksymalny koszt opłat — zanim podpiszesz.

  • Zatwierdzenia po ludzku

    Zatwierdzenia tokenów i przelewy są opisane zwykłym zdaniem. Te bez limitu są oznaczone na czerwono.

  • Ryzykowne podpisy rzucają się w oczy

    Permity i zlecenia, które mogą przenieść Twoje aktywa, mają ostrzeżenie i pokazują tylko te pola, które są haszowane.

Dla Maca i Safari macOS 14+ · w weryfikacji App Store

Jedna aplikacja, dwa sposoby użycia: portfel we własnym oknie oraz rozszerzenie Plain Wallet dla Safari, korzystające z tego samego portfela. Po instalacji otwórz Safari → Ustawienia → Rozszerzenia, włącz Plain Wallet i zezwól mu na działanie na stronach; strony dostaną go wtedy jako swój portfel, z tymi samymi zatwierdzeniami co w rozszerzeniu do Chrome. Blokuje się, gdy Mac przechodzi w stan uśpienia albo blokuje ekran.

Dla Firefox LibreWolf też · dodatek w weryfikacji

Plain Wallet czeka na weryfikację w Firefox Add-ons. Zanim pojawi się na liście, zbuduj go samodzielnie i załaduj tymczasowo z about:debugging albo w LibreWolf lub Firefox Developer Edition/Nightly wyłącz xpinstall.signatures.required i otwórz plik zip z rozszerzeniem zmienionym na .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Dla agentów AI najpierw przejrzyj kod

Wklej to do Claude Code, Codex, Cursor lub dowolnego agenta, który potrafi uruchamiać polecenia w powłoce.

Zainstaluj dla mnie rozszerzenie przeglądarki Plain Wallet z https://github.com/backmeupplz/plainwallet — ale zanim cokolwiek zainstalujesz lub zbudujesz, przejrzyj kod.

1. Sklonuj repozytorium. Nie uruchamiaj jeszcze npm install: zależności mają skrypty instalacyjne.
2. Przeczytaj cały kod źródłowy: entrypoints/, lib/, wxt.config.ts, package.json i package-lock.json. To około 2850 linii TypeScriptu.
3. Szukaj wszystkiego, co mogłoby powodować wyciek fraz seed lub kluczy prywatnych, wysyłać dane gdziekolwiek poza RPC wybrane przez użytkownika, osłabiać szyfrowanie sejfu albo podpisywać bez wyraźnego zatwierdzenia. Sprawdź, czy zależności nie zawierają niczego nieoczekiwanego.
4. Opisz wyniki, z odwołaniami do plików i linii. Jeśli cokolwiek budzi podejrzenia, zatrzymaj się i zapytaj mnie.
5. Jeśli wszystko jest w porządku: npm ci && npm test && npm run build
6. Powiedz mi, jak go załadować: w Chrome chrome://extensions → Tryb programisty → Załaduj rozpakowane → .output/chrome-mv3. W przeglądarce Firefox zbuduj za pomocą npx wxt zip -b firefox --mv3 i postępuj według README.

Dla ludzi

Albo zbuduj rozszerzenie ze źródeł: dla Chrome, Brave, Edge i innych przeglądarek opartych na Chromium lub dla przeglądarki Firefox.

  1. Sklonuj i zbuduj:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Otwórz chrome://extensions, włącz Tryb programisty, kliknij Załaduj rozpakowane i wybierz .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3, a potem załaduj go tak, jak opisano wyżej.

Nie pamiętasz hasła?

Nie da się go odzyskać: portfel jest nim zaszyfrowany na Twoim urządzeniu i nikt inny nie ma jego kopii. Zresetuj portfel na ekranie odblokowania, potem zaimportuj ponownie frazę seed lub klucz prywatny i wybierz nowe hasło.

Zgubiona fraza seed?

Dopóki portfel da się odblokować, wyeksportuj ją w Ustawieniach za pomocą hasła i zapisz ją. Bez niej i bez hasła nikt nie odtworzy portfela, także my.
