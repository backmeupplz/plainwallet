Ves lo que firmas.

Cada firma requiere un clic en la ventana propia de la cartera. La transacción se prepara por completo antes y se firma exactamente esa.

  • Sabes qué envías

    Destinatario, importe y el máximo que puede costar en comisiones, antes de firmar.

  • Aprobaciones explicadas

    Las aprobaciones y transferencias de tokens se convierten en una frase sencilla. Las ilimitadas se marcan en rojo.

  • Las firmas de riesgo destacan

    Los permits y las órdenes que pueden mover tus activos llevan una advertencia y muestran solo los campos que se firman con el hash.

Para Mac y Safari macOS 14+ · Mac App Store

Una sola app con dos formas de usarla: la cartera en su propia ventana y la extensión de Plain Wallet para Safari, que comparten la misma cartera. Tras instalarla, abre Safari → Ajustes → Extensiones, activa Plain Wallet y permítela en los sitios web; a partir de ahí los sitios la tendrán como cartera, con las mismas aprobaciones que la extensión de Chrome. Para Firefox también LibreWolf · complemento en revisión

Plain Wallet está a la espera de revisión en Firefox Add-ons. Hasta que se publique, compílala y cárgala temporalmente desde about:debugging; en LibreWolf o en Firefox Developer Edition/Nightly, desactiva xpinstall.signatures.required y abre el zip renombrado a .xpi.

git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npx wxt zip -b firefox --mv3   # → .output/plainwallet-<version>-firefox.zip

Para agentes de IA primero revisa

Pega esto en Claude Code, Codex, Cursor o cualquier agente que pueda ejecutar comandos de shell.

Instálame la extensión de navegador Plain Wallet desde https://github.com/backmeupplz/plainwallet, pero revisa el código antes de instalar o compilar nada.

1. Clona el repositorio. No ejecutes todavía npm install: las dependencias tienen scripts de instalación.
2. Lee todo el código fuente: entrypoints/, lib/, wxt.config.ts, package.json y package-lock.json. Son unas 2.850 líneas de TypeScript.
3. Busca cualquier cosa que pueda filtrar frases semilla o claves privadas, enviar datos a algún sitio que no sea el RPC elegido por el usuario, debilitar el cifrado de la bóveda o firmar sin una aprobación explícita. Comprueba si las dependencias contienen algo inesperado.
4. Cuéntame lo que encuentres, con referencias a archivos y líneas. Si algo resulta sospechoso, detente y pregúntame.
5. Si está limpio: npm ci && npm test && npm run build
6. Explícame cómo cargarla: en Chrome, chrome://extensions → Modo desarrollador → Cargar descomprimida → .output/chrome-mv3. Para Firefox, compila con npx wxt zip -b firefox --mv3 y sigue el README.

Para personas

O compila la extensión desde el código fuente para Chrome, Brave, Edge y otros navegadores basados en Chromium, o para Firefox.

  1. Clona y compila:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Abre chrome://extensions, activa Modo desarrollador, haz clic en Cargar descomprimida y elige .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3 y cárgala como se describe más arriba.

Soporte

Envía tus preguntas por correo a plainwallet@borodutch.com, o publica los informes de errores y las peticiones de funciones en el gestor de incidencias de GitHub; el desarrollador responde a ambos. Nunca publiques tu contraseña, frase semilla o clave privada ahí ni en ningún otro sitio.

¿Has olvidado tu contraseña?

No se puede recuperar: la cartera se cifra con ella en tu dispositivo y nadie más tiene una copia. Restablece la cartera desde la pantalla de desbloqueo, vuelve a importar tu frase semilla o clave privada y elige una contraseña nueva.

¿Has perdido tu frase semilla?

Mientras la cartera aún se desbloquee, expórtala en Ajustes con tu contraseña y anótala. Sin ella y sin la contraseña, nadie puede restaurar la cartera, tampoco nosotros.
