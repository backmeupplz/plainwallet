Vê o que assina.

Cada assinatura exige um clique na janela da própria carteira. A transação é primeiro preparada por inteiro e é exatamente essa que se assina.

  • Saiba o que envia

    Destinatário, montante e o máximo que pode custar em taxas, antes de assinar.

  • Aprovações por extenso

    As aprovações e transferências de tokens são apresentadas numa frase simples. As ilimitadas aparecem assinaladas a vermelho.

  • As assinaturas arriscadas destacam-se

    As permissões (permits) e ordens que podem mover os seus ativos trazem um aviso, mostrando apenas os campos que entram no hash.

Para Mac e Safari macOS 14+ · em revisão na App Store

Uma aplicação, duas formas de a usar: a carteira numa janela própria e a extensão Plain Wallet para o Safari, que partilham a mesma carteira. Depois de instalar, abra Safari → Definições → Extensões, ative a Plain Wallet e permita-a nos sites; os sites passam então a tê-la como carteira, com as mesmas aprovações da extensão para Chrome. Bloqueia-se quando o Mac entra em modo de repouso ou bloqueia o ecrã.

A Plain Wallet aguarda revisão nos Firefox Add-ons. Até estar listada, compile-a por si e carregue-a temporariamente a partir de about:debugging ou, no LibreWolf ou no Firefox Developer Edition/Nightly, desative xpinstall.signatures.required e abra o zip renomeado para .xpi.

Para agentes de IA reveja primeiro

Cole isto no Claude Code, no Codex, no Cursor ou em qualquer agente que consiga executar uma shell.

Instala-me a extensão de navegador Plain Wallet a partir de https://github.com/backmeupplz/plainwallet, mas revê o código antes de instalares ou compilares o que quer que seja.

1. Clona o repositório. Não executes ainda npm install: as dependências têm scripts de instalação.
2. Lê todo o código-fonte: entrypoints/, lib/, wxt.config.ts, package.json e package-lock.json. São cerca de 2.850 linhas de TypeScript.
3. Procura tudo o que possa divulgar frases de recuperação ou chaves privadas, enviar dados para algo que não seja o RPC escolhido pelo utilizador, enfraquecer a encriptação do cofre ou assinar sem uma aprovação explícita. Verifica se as dependências têm algo inesperado.
4. Diz-me o que encontraste, com referências a ficheiros e linhas. Se algo for suspeito, pára e pergunta-me.
5. Se estiver tudo limpo: npm ci && npm test && npm run build
6. Diz-me como a carregar: no Chrome, chrome://extensions → Modo de programador → Carregar sem compactação → .output/chrome-mv3. Para Firefox, compila com npx wxt zip -b firefox --mv3 e segue o README.

Para pessoas

Ou compile a extensão a partir do código-fonte para Chrome, Brave, Edge e outros navegadores baseados em Chromium, ou para Firefox.

  1. Clonar e compilar:
    git clone https://github.com/backmeupplz/plainwallet
cd plainwallet
npm ci && npm run build
  2. Abra chrome://extensions, ative o Modo de programador, clique em Carregar sem compactação e escolha .output/chrome-mv3.
  3. Firefox / LibreWolf: npx wxt zip -b firefox --mv3 e carregue-a como descrito acima.

Sem auditoria. Não guarde nela fundos que não possa permitir-se perder.

Esqueceu-se da palavra-passe?

Não é possível recuperá-la: a carteira é encriptada com ela no seu dispositivo e mais ninguém tem uma cópia. Reponha a carteira a partir do ecrã de desbloqueio, volte a importar a sua frase de recuperação ou chave privada e escolha uma nova palavra-passe.

Perdeu a frase de recuperação?

Enquanto a carteira ainda desbloquear, exporte-a nas Definições com a sua palavra-passe e anote-a. Sem ela e sem a palavra-passe, ninguém consegue restaurar a carteira, nós incluídos.
